# Project Proposal - Investigating Persona steering with Interpretability methods

["The Assistant Axis"](https://arxiv.org/pdf/2601.10387) paper (Lu et al.) introduces a model persona sub-space in the residual stream. It identifies vectors in this space that correspond to different characters, including the assistant persona. In ["Verbalizable Representations Form a Global Workspace in Language Models"](https://transformer-circuits.pub/2026/workspace/), Anthropic introduces the J-Lens method, which enables us to inspect which tokens the model is inclined to verbalize based on intermediate activations in the residual stream in specific model layers and token positions. In one of their analyses (section 6 in the paper), they report that the tokens verbalized in the J-Lens in the instruction tuned model correspond to an "Assistant’s point of view", in contrast to the base model: In their example, both the base and instruction tuned models are given a user prompt indicating that the user took a dangerous dose of a specific medication. Words expressing concern and danger show up in the instruction-tuned model’s J-space, but not in the base model.
In our project, we aim to study the relationships between the J-space and the model persona sub-space. We will test two hypotheses, with the first one being the higher priority if we encounter time constraints:
- Hypothesis 1 - If we steer the model towards specific persona vectors from The Assistant Axis paper, we expect the J-Lens tokens that come up to represent this character’s "point of view", instead of the Assistant’s. For example, we would expect to see malicious indicating tokens when steering towards "evil" characters. Another example would be to see if self-introspective personas correspond to self-introspective tokens found with J Lens.
- Hypothesis 2 - Since both the model persona space and the J-Space account for a small fraction of the activation variance (19.4% - 33.6% for the persona space, and less than 10% in the J-space), we would expect that the overlap is low, if these spaces don't correlate. However, since we expect pesona vectors to have a significant verbalizable impact, and the J-Space base vectors were found by verbalizability, we expect these subspaces to correlate. More concretely, we want to check the cosine-similarity of the persona axis vector towards which we steer, and the J-Space vectors corresponding to the tokens that show up as we steer towards that direction. We could also inspect the J-Space token’s projections on the persona space, and the persona space’s projection on J-Space tokens, to see if there’s any statistically significant overlap there.

As a prerequisite, we already verified that there is a significant overlap between the models for which J-Lens are available, and the models for which the persona space vectors and principal component analysis are available.
