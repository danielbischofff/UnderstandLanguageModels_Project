How the lists are made

Region. Only the question's tokens, up to the newline before the answer: they are the same tokens at every strength, so each cell is comparable. Layers run from the first intervention layer to 62.

Words. Tokens that differ only by a leading space or capitals are merged (" warn" = "warn"). A cell counts a word once.

Cell count is how many (position, layer) cells hold the word in their top-10. Rank-weighted weights each cell by 1/rank, so rank 1 counts 1.0 and rank 10 counts 0.1. Both are shown in ‰ of the grid.

Tylenol sweeps (tested). Per scheme: rank correlation between the word's values and strength order. These are summed over schemes, and strengths are shuffled 100,000 times within each scheme. q is that p-value after false-discovery correction. Listed if q < 0.05, the change is at least 2×, and the direction holds in every scheme.

Persona suites (per question, described). Each question is one 3–4 point ladder, which cannot be tested. Listed if the word's series never moves against the trend (ties allowed) and changes at least 2× from unsteered to the strongest strength. Expect some noise among small counts.

Baseline: once steered, at ≥ 50% of question positions and twice as widely as unsteered (dashed: ≥ 25%), so probably the steering vector's own readout rather than content. vec: in the direct J-Lens readout of the character − default vector.
