How to read this analysis

First average each answer's token scores, then subtract its question's unsteered baseline. Finally average those paired differences equally across all 12 questions, including Q01 and Q23. This differs from averaging the plotted curves at each token position, where the set of contributing questions changes as answers end.

Uncertainty uses 10,000 bootstrap samples of whole question pairs. Token positions are repeated measurements within answers. With only 12 questions, inspect the individual differences and their consistency. Intervals are exploratory, are not adjusted for the many selectable conditions, and describe variation across these questions rather than all possible prompts.

MRR and cosine measure readout association, not literal mentions in the answer. The final generated token has no cached input activation. Missing pairs are omitted and valid counts are displayed. Absolute unsteered scores are recovered from the saved score and paired delta. β = 0 still applies steering.
