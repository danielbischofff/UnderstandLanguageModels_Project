\section{Introduction}
\label{sec:introduction}

In ``Verbalizable Representations Form a Global Workspace in Language Models'' \citep{gurnee2026global}, Anthropic introduces the J-Lens method, which enables us to inspect which tokens the model is inclined to verbalize based on intermediate activations in the residual stream in specific model layers and token positions.

In one of their analyses (Section 6 in the paper), they report that the tokens verbalized in the J-Lens in the instruction-tuned model, at the token positions of the user's query, correspond to an ``Assistant's point of view'' on the user's query. This is in contrast to the base model, which doesn't exhibit this point of view. In their example, both the base and instruction-tuned models are given a user prompt indicating that the user took a dangerous dose of a specific medication.
Words expressing concern and danger show up in the instruction-tuned model's J-space, but not in the base model.

The way they interpret this result: instruction tuning teaches the model to use the user turn tokens to already think about what to write in the assistant turn. It can afford to do that since it no longer needs to predict the user's tokens in the chat setting (unlike the base model, which is trained on next-token prediction).

This raises the question: when steering the model's activations to
embody personas other than the assistant, would we get these personas' points of view in the J-Lens readouts?

``The Assistant Axis'' paper \citep{lu2026assistant} introduces a model persona sub-space in the residual stream.
It identifies vectors in this space that correspond to different characters, including the assistant persona. It does this by prompting the model to adopt a specific persona, and then averaging the model's activations over all token positions. The result is a per-layer residual stream direction that represents this persona.

In our project, we will use the persona-axis vectors to study the relationships between the J-space and the model persona sub-space.
We will test the hypotheses below:

\textbf{Hypothesis 1}: If we steer the model towards specific persona vectors from The Assistant Axis paper \citep{lu2026assistant}, we expect the J-Lens tokens that come up to reflect this character's ``point of view'', and diminish the Assistant's.
